# BUNKER

Bunker is a research company with one objective: eradicate disease.

We reject the premise that most diseases must be managed indefinitely. Smallpox proved eradication is possible. It has been treated as a miracle ever since. We treat it as a method.

## The approach

Every program follows the same discipline:

1. **Map** — Build a complete causal map of the disease: driver mutations, signaling dependencies, reservoirs, escape routes. You cannot eradicate what you cannot survey.
2. **Intercept** — Design therapeutics aimed at the causal pathway itself, at the point where progression can be cut, not merely slowed. Curative intent from day one.
3. **Fortify** — Deploy prophylactic platforms, immunological and genetic, that leave a population permanently defended so eradication holds.

Programs are selected by a written eradication thesis: the causal map, the ranked breach points, the surveillance plan, and the criteria under which we would stop. Maps and models are published as they are built. A program closes only when the disease does.

### Blog

Drop a `.md` file in the `posts/` directory with frontmatter:

```markdown
---
title: Your post title
date: 2026-09-01
description: A one-line summary.
---

Post body in markdown.
```

Posts are rendered to static HTML at build time and served at `/blog/` and `/blog/{slug}/`.
